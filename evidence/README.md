# Evidence and screenshots

Store screenshots and supporting artifacts for each investigation in a scenario-specific subfolder, for example:

```text
evidence/
└── 2026-11-04-soc-simulator-email-firewall/
    ├── 01-dashboard-results.png
    ├── 02-email-alert-8814.png
    ├── 03-url-clean-result.png
    ├── 04-amazon-phishing-email.png
    ├── 05-firewall-alert-8816.png
    ├── 06-url-malicious-result.png
    └── 07-microsoft-phishing-email.png
```

For each image, add a caption in the investigation report explaining what it proves. Prefer screenshots of the actual simulator evidence over decorative images.
